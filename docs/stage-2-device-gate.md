## 准备

- [ ] 服务端：从 `fix/stage-2-client-usable` 分支构建并部署（Docker 或直跑），
      记下访问地址（局域网 `http://<IP>:8080` 或反代域名）。
- [ ] 客户端：用 `dotnet build AnyDrop.App -f net10.0-android -c Release`
      构建 APK，按 D4 自用分发（签名侧载）装到真机；不要走应用商店。
- [ ] 真机：Android 手机一部（主测），另备一台设备或浏览器开 Web 端作对照。
- [ ] 测试账号：新建账号并登录；准备一个 500MB 左右的测试文件
      （`dd if=/dev/urandom of=test500.bin bs=1M count=500`，记下 SHA-256），
      以及一个 25MB 文件作快速对照。
- [ ] 网络：可开关 Wi-Fi/飞行模式；弱网可用系统限速或走到信号差的位置。

## 客户端回归（Android 真机）

### 会话与 Token（S2-01/02/03）
- [ ] **隔夜会话**：登录后让应用在后台放 **24 小时以上**
      （AccessToken 默认有效期 24h，过期前 5 分钟应自动刷新；放一夜
      8 小时还不够触发刷新），之后打开直接可用，**无需重新登录**；
      若被登出则记为失败。
- [ ] **401 不误杀登录页**：在登录页故意输错密码，不应弹出“登录已过期”提示，
      也不应清掉已保存的 Token。

### 连接与回补（S2-04/05）
- [ ] **5 分钟断线回补**：开飞行模式 5 分钟，期间用 Web 端向当前话题发 3 条
      消息；恢复网络后，MAUI 端自动重连，3 条消息**全部出现且无重复**。
- [ ] **换服务端地址**：设置页改服务端地址到另一个可达实例，Hub 应重建并
      连上新地址（不再连旧地址）；切回原地址亦然。
- [ ] **离线发件箱**：飞行模式下发 2 条文本，关机杀进程重开，联网后 2 条
      自动补发，话题内各出现一次；发件箱提示消失。
- [ ] **输入草稿**：输入框打一半字，杀进程重开，同一话题草稿仍在；
      切换话题再切回，草稿按话题各自保留；发送成功后草稿清空。
- [ ] **断线轮询兜底**：SignalR 断开且重连中时，列表仍能通过轮询看到新消息。

### 分享链（S2-06）
- [ ] **相册多选分享**：相册选 3 张图 → 分享到 AnyDrop，3 个文件均上传成功，
      类型为图片（不是 `application/octet-stream`）。
- [ ] **文件多选分享**：文件管理器多选 2 个文件分享，全部到达。
- [ ] **杀进程不丢分享**：分享到 AnyDrop 后**立即杀进程**再打开应用，
      待分享内容仍在（磁盘持久化），可完成上传。
- [ ] **文本分享**：浏览器/备忘录分享一段文本，正常到达。

### 分片上传（S2-07，硬门）
- [ ] **弱网 500MB 断点续传**：上传 500MB 文件，途中**断网两次、杀进程一次**，
      每次恢复后继续上传，最终完成；话题内**恰好一条**文件消息；
      下载后 SHA-256 与源文件一致；服务端磁盘上**恰好一份**文件。
- [ ] **超限拒绝**：尝试上传 >500MB 文件，初始化即被拒绝（413），无残留会话。
- [ ] **小文件仍走单次上传**：传一个 5MB 文件，正常完成（<20MB 单次路径）。

### 接线清零（S2-08）
- [ ] **选图多选 + 真实 MIME**：应用内选图按钮一次选多张，全部上传；
      选 PNG 图上传后服务端记录的 MIME 是 `image/png`（不是 `image/jpeg`）。
- [ ] **权限拒绝**：系统设置里撤掉相册权限后点选图，应用内出现“去设置”
      提示条；点“去设置”跳到系统应用详情页；重新授权后选图恢复。
- [ ] **通知点按跳转**：用 Web 端向**非当前话题**发一条消息，真机收到通知；
      点通知打开应用并跳到该话题。
- [ ] **归档区**：归档一个话题，侧栏归档区展开后能看到它；取消归档后回到主列表。
- [ ] **设置页安全区**：改“定时销毁时长/自动清理”并保存，刷新 Web 端设置页，
      数值一致；手动清理 1 个月前消息可执行并显示条数。
- [ ] **通知权限**：设置页“请求权限”能弹出系统授权框；授权后通知正常到达。

### 清单/权限（S2-09）
- [ ] **音频文件选择**：选一个音频文件（.mp3/.m4a）上传成功
     （验证新增的 `READ_MEDIA_AUDIO`）。
- [ ] **分享入口**：相册/文件管理器/浏览器分享菜单里均有 AnyDrop。

## Web 端回归（桌面浏览器 + 手机浏览器）

- [ ] **浏览器时区**：消息时间、侧栏最后消息时间、搜索结果时间、设置页
      “首次发现”时间均与本地时间一致（容器为 UTC 时差 8 小时即为失败）。
- [ ] **首屏刷新**：首次打开首页，时间在拿到浏览器时区后自动纠正，
      不需手动刷新或等新消息。
- [ ] **草稿**：输入框打一半字，刷新页面，草稿仍在；切换话题各自保留；
      发送后清空。
- [ ] **电路保留**：手机浏览器锁屏/切后台 5 分钟后回来，页面仍可操作，
      无需整页刷新（验证 10 分钟电路保留）。
- [ ] **文件夹拖入**：把一个文件夹拖到聊天区，出现“暂不支持拖入文件夹”提示，
      且不上传任何内容；再拖单个文件，正常上传。
- [ ] **上传取消与超时**：上传一个大文件，中途点“取消上传”，占位气泡变失败态，
      可点重试；失败原因显示本地化文案而非英文原文。
- [ ] **登录/设置容错**：断网后打开设置页应显示“加载设置失败”而非白屏；
      登录页断网时仍可输入密码提交（失败后显示可重试的错误）。
